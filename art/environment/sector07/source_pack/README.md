# GUANDITO — Sector 07 Environment Pack v1

Master source: 1536×1024px (native generated output; not falsely labeled 4096×3072).

## Important
This package does **not** upscale the source. It preserves native pixels.
`structure_32_grid.png` is a deterministic 512×352 atlas divisible into 32×32 cells.
Other folders contain native regional source atlases plus a manifest so Codex can integrate clean regions without guessing.

Background panoramas are opaque by design. Character art is not included and must never be replaced from environment art.

See `manifest.json` and `CODEX_IMPLEMENTATION_PROMPT.md`.
