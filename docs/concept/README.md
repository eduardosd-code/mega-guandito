# Referencias visuales oficiales de GUANDITO

La autoridad visual principal del protagonista es `assets/concept/guandito_concept.png`, complementada por `assets/characters/guandito/ConcepArt_Protagonista.png`. La referencia ambiental de Sector 07 es `assets/concept/sector_07_design.png`.

Estas láminas fijan el diseño aprobado: casco verde oscuro, placa frontal metálica clara, visor negro con ojos digitales verdes, sensores laterales, antenas, reactor verde, cuerpo grafito, armadura verde, placas blancas, botas mecánicas, marca `01`, cables posteriores y Martillo de Pulso Cinético industrial.

Las imágenes son referencias compuestas. **No deben recortarse ni utilizarse directamente como sprites runtime.** El arte definitivo debe producirse como spritesheet/atlas independiente, con canvas lógico de **64×64 px por frame**, filtrado nearest-neighbor y pivote constante en el centro de los pies.

Copias históricas equivalentes permanecen en `assets/concept/`; deben depurarse únicamente tras una revisión humana para no perder material aprobado.
